# Demo script

1. Launch the backend using `npm run develop` inside `backend`.
2. Launch the app with `flutter run` inside `mobile_app`.
3. Use the login screen and select `Continue in demo mode`.
4. Navigate the dashboard to review climate, energy, and security widgets.
5. Open a room and explain the blocked heating scenario.
6. Inspect the routines screen to see workflow details and confidence states.
7. Toggle theme or backend settings to demonstrate configuration flexibility.
